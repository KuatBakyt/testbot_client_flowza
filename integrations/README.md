# API приёма заявок

В актуальном `KuatBakyt/flowza-crm` приложение `flowza_bot_api` уже встроено.
Скопировать папку, менять INSTALLED_APPS или urls.py не требуется.
Обновите CRM, соберите Docker и выполните миграции по её README.
Бот остаётся отдельным приложением и использует `/api/v1/bot/orders/` через HTTP/JWT.

Папка integrations/flowza_bot_api сохранена как совместимый образец для старых
версий CRM. Она не запускается в процессе Telegram-бота и не нужна новой CRM.
Не накладывайте её поверх встроенного приложения CRM.
